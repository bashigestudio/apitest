## AI大模型中转站相关技术话题解析以及常见问题解答

**API密钥泄露了怎么办？**

请立即在 API 密钥 页停用或删除这把密钥，再新建一把替换。停用后它发起的请求会立刻被拒绝。平时请把密钥当作银行卡密码保管：不要发到群聊、不要写进代码仓库。每把密钥都可以单独设置额度上限、5 小时 / 日 / 7 天消费限额、有效期和 IP 白名单，给不同项目或成员分开发放，出问题时只影响一把。

**请求报错了，怎么排查？**

错误信息里的 [code: …] 可以在 错误码说明 中查到原因与处理办法。最常见的是密钥写错（401）、余额不足，或接口地址多写 / 少写了 /v1——Anthropic 协议用根地址，OpenAI 协议用带 /v1 的地址。每笔请求的模型、用量与费用都能在控制台「使用记录」中查询。

**有速率或并发限制吗？**

并发上限由你所在的分组或套餐决定，超出时本站返回 429，响应头带 Retry-After（建议的重试间隔，秒），按它退避重试或调低客户端并发即可。上游服务商限流同样表现为 429。密钥上的消费限额（5 小时 / 日 / 7 天）按金额计算，用完后该密钥暂停调用，时间窗口重置后自动恢复。

**调用的是官方模型吗？**

是。请求按你指定的模型转发至 Anthropic 与 OpenAI 官方上游，不降级、不替换；流式输出、工具调用与长上下文按所选模型的能力完整提供。

**用哪个模型名？我的密钥能调用哪些模型？**

模型名见上方「模型 ID」或 模型广场。密钥可调用其所在分组授权的模型，用 GET /v1/models 可以列出当前密钥可用的全部模型。
